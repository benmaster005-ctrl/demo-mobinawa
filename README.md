# Mobinawa — prototype v48

Prototype de l'application mobile Mobinawa (React + Vite + Tailwind CSS).
Le mémo de reprise du projet se trouve dans `MEMO.md`.

## Structure

- `Mobinawa.jsx` : l'application complète (fichier Mobinawa_v48.jsx)
- `main.jsx` : point d'entrée qui affiche l'application
- `index.html`, `vite.config.js`, `tailwind.config.js` : configuration

## Mise en ligne (Vercel ou Netlify)

Importer ce dépôt GitHub dans Vercel ou Netlify. Réglages détectés automatiquement :

- Commande de build : `npm run build`
- Dossier publié : `dist`

## Nouvelle version (v49, v50…)

Remplacer le contenu de `Mobinawa.jsx` par le nouveau fichier, en gardant ce nom.
L'hébergeur redéploie automatiquement après chaque modification sur GitHub.

## Lancer en local (facultatif)

```
npm install
npm run dev
```
